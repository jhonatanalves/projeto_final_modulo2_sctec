# Dados

`telco_churn.csv` é a base **Telco Customer Churn** (IBM), disponível no Kaggle:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

- Arquivo original: `WA_Fn-UseC_-Telco-Customer-Churn.csv`, renomeado para `telco_churn.csv`.
- 7.043 clientes, 21 colunas; alvo: `Churn` (Yes/No).
- Licença: dados de exemplo públicos da IBM, distribuídos no Kaggle.
